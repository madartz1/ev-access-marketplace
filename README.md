# EV Access Marketplace

B2B electric vehicle rental marketplace for manufacturers, dealers and fleet operators.

The full application source is packaged in the EV Access GitHub Web App ZIP provided in ChatGPT. This repository is being initialized for the source upload.

## Planned stack
Next.js 14, React, Prisma, PostgreSQL.

## Status
Development MVP. Do not accept real rentals or payments until insurance, TLC compliance, booking, and security checks are completed.
